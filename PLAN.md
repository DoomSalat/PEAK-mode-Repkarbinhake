# Repkarbinhake — план работы

Мод для PEAK: игроки связываются физичной верёвкой и вместе лезут в гору. Верёвку можно взять в руки и сматывать/разматывать колесом мыши; держащий верёвку становится устойчивым, а цепочка держащих усиливает друг друга.

Отмечаем `[x]` по мере выполнения. Этап закрыт только после подтверждения пользователя.

## Принятые решения

| Тема | Решение |
|---|---|
| Физика | Каждый клиент тянет **только своего** персонажа силой натяжения (пружина + демпфер, только при натянутой верёвке) к синхронизированной позиции напарника. Ванильный `Rope` не используется: его джоинты симулирует только владелец. |
| Визуал | Локальная verlet-верёвка между игроками, материал ванильной верёвки, огибает рельеф. |
| Связка | Только глядя на игрока (не на верёвку), **удерживать `G`** — кольцо на прицеле заполняется, как у костра/статуи: не связаны → связаться (`TieHoldSeconds`), связаны → отцепиться (`UntieHoldSeconds`). Что делать, решается в момент нажатия. Согласие не нужно, любой участник может отцепиться. Связей у игрока сколько угодно. |
| Подбор | Навёлся на верёвку → ванильное «взаимодействие» (E), верёвка подсвечивается контуром как предметы. Взять могут только двое её участников. |
| Длина и сматывание | Свободная верёвка **всегда полной длины** `MaxLength` (общая для лобби, от хоста). Держишь верёвку → колесо временно укорачивает её; отпустил → снова полная. Сматывание против нагрузки ограничено **силой рук** `ArmStrength`: скорость = 1 − нагрузка / сила рук, но не ниже 15% (`MinReelInFactor`): вытянуть можно всегда, но под тяжёлым грузом медленно и с полной тратой стамины. Сила рук по умолчанию 12. Натяжение действует **вдоль пути верёвки** (через край уступа), а не по прямой между игроками. Разматывание всегда свободное. Взял предмет в руки → верёвка отпускается. |
| Устойчивость | Держащий верёвку гасит долю натяжения (`BraceResistance`). Каждый другой держащий в той же связке добавляет `GroupBonus`. Игрок, держащий твою верёвку и сам держащий, передаёт тебе часть своей устойчивости (`ChainSupport`, рекурсивно по цепочке). Потолок — `MaxStability`, сдвинуть всё же можно. |
| Сеть | Схема «для всех»: состояние связок в Photon room properties, ключ на связку `rkb.link.<A>_<B>` = `[tied, длина, кто держит, автор, номер записи]`. Длину пишет только держащий (~10 Гц), создать/развязать может любой участник. Развязка — запись `tied=false`, не удаление ключа. Пока своя запись не вернулась эхом, чужие записи по этой связке игнорируются (сервер доставляет всем в одном порядке). Хост чистит связки вышедших и раздаёт общие настройки. Мод нужен всем. Подробно — `index.md`. |
| Двое держат одну верёвку | **Оба могут держать одновременно.** У каждого конца своя смотка: длина = полная − смотка A − смотка B (не меньше `MinLength`). Оба упираются (устойчивы); оба сматывают — перетягивание. Сеть: каждый конец пишет только его владелец (отдельный ключ на конец → нет конфликтов записи); связка (завязана/нет) — общий ключ с номером «поколения», чтобы устаревшие записи концов от прошлой завязки игнорировались. **Реализовано в Core и песочнице.** |
| Висящий и гравитация PEAK | В воздухе PEAK добавляет гравитацию до 20 м/с² по `sinceGrounded`. Пока натянутая верёвка держит игрока вверх, ограничиваем его `sinceGrounded` (в игре есть `Character.ClampSinceGrounded`) — висящий не «тяжелеет» и не копит урон от падения. Порог `HangAirTimeCap` > 0.2 с, чтобы стамина не восстанавливалась. В песочнице: галочка `RopeSupportCapsAirTime`. |
| Стамина висящего | Как в игре: не тратится (не лезет) и не восстанавливается (не на земле). Ничего не меняем. |
| Опора и руки | На земле: держать, упираться, сматывать (стамина), разматывать. В воздухе: держать и разматывать (спуск), но **не упираться и не сматывать** — висящий не может вытянуть себя сам и не ослабляет свою верёвку. Лезет по стене: **с верёвкой работать нельзя**, взятый конец отпускается. Правило «оба держат → никто не сматывает» не вводим — перетягивание на земле остаётся. |
| Смерть и потеря сознания | **Смерть** (`data.dead`) — все связки умершего развязываются: развязывает клиент самого умершего, хост дублирует (на случай вылета). После воскрешения связки сами не возвращаются. **Без сознания** (`passedOut` / `fullyPassedOut`) — игрок жив: связки остаются, его можно тащить, но руками он ничего не делает — его конец отпускается, не упирается, не сматывает (опора `Unconscious`). |
| Выход из игры | Игрок вышел / отключился — все его связки развязываются. Делает хост (`DepartedUntieRule`): при `OnPlayerLeftRoom`, при смене хоста (`OnMasterClientSwitched` — новый хост сверяет связки со списком игроков) и при входе в комнату (чистит хвосты давно вышедших). Неактивные игроки (`IsInactive`, окно переподключения Photon) считаются вышедшими. |
| Звуки | В моде звуки карабина играются через `SFX_Player.instance.PlaySFX(SFX_Instance, позиция)` — `SFX_Instance` собирается в рантайме из наших клипов. Так звук идёт в группу микшера игры SFX (`defaultMixerGroup`) и слушается ползунка громкости SFX в настройках PEAK. В песочнице: `SandboxMixer` (Master → SFX), источник `CarabinerAudio` выводится в SFX. |
| Стамина за смотку | Тратится только на смотку под нагрузкой: `ReelStaminaPerMeter` (полная полоса = 1) за метр при нагрузке `ArmStrength`, пропорционально нагрузке. Провисшую сматывать бесплатно, разматывать бесплатно, просто держать бесплатно (страховка не должна выдыхаться). При нуле стамины под нагрузкой сматывать нельзя. |
| Страховка на стене | Пока союзник, с которым я связан, **держит нашу верёвку (E)**, а я лезу по стене с 0 стамины — скольжение не разгоняется выше медленного: `data.outOfStaminaClimbingFor` ограничивается `BelaySlideCap` (в игре скорость скольжения ∝ `(t·0.15)²`, t до 5 с; потолок 2 с ≈ 9 % от максимума; `0` = полное обнуление). Время в воздухе тоже ограничено (`ClampSinceGrounded(HangAirTimeCap)`), чтобы при срыве верёвка ловила без накопленной гравитации. Применяет каждый клиент к своему персонажу. Проверить можно только в игре — в песочнице нет лазания по стенам. |
| Конфиг | BepInEx config, редактируется в игре через **ModConfig**. Длина верёвки общая для лобби (берётся значение хоста). Клавиша связки — строка input path (`<Keyboard>/g`), ModConfig даёт её переназначить. |

#### Приоритет действий (E — ванильная логика + наша верёвка поверх)
Игра выбирает цель для E в `Interaction.DoInteractableRaycasts` (вызывается из `Interaction.LateUpdate`), сверху вниз:
1. Несомый игрок — если выбран слот 4 (рюкзак / несомый).
2. Предмет, прилипший ко мне (липкие предметы), — когда смотришь строго вверх или вниз.
3. Луч из камеры на `Interaction.distance` (2 м): ближайший коллайдер; если он `IInteractible` и доступен — цель.
4. Иначе сфера радиуса `area` (0,5) до точки луча: интерактив с наименьшим углом к взгляду, не закрытый рельефом.
5. Шипы / стрелы, застрявшие во мне.
6. **Наша верёвка** — постфикс поверх (`InteractionPatches`): только если игра не нашла ничего и вызов обычный (без `overrideDistance`), иначе не трогаем. Ванильную логику не меняем, другие моды, патчащие этот метод, работают как раньше.

G (связать / отцепить) — отдельная клавиша, свой выбор цели (игрок / манекен в радиусе `Interaction.distance`). Пока есть цель G, наша верёвка под прицелом не подсвечивается и в E не подставляется.
